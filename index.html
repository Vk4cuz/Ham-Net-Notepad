    Ham Net Notepad

    Created by

    Gary Crothers VK4CUZ

    Purpose

    A lightweight amateur radio net participant tracker.

    Designed for operators participating in nets rather than Net Control.

    Project Origin

    This project was inspired by years of maintaining amateur radio net participant lists in OneNote.

    The goal was to create a simple local-first application that allows operators to:

    • Build a running order as stations check in
    • Reorder stations easily during a net
    • Maintain participant information
    • Record session notes
    • Save session history

    without requiring cloud services, subscriptions, accounts, or complex logging software.

    Current Version Features

    • Multiple net support
    • Shared station database
    • Running order management
    • Parked station management
    • Session notes
    • Session history
    • JSON import/export
    • Offline operation

    Ham Net Notepad Help

    Purpose

    Ham Net Notepad is designed for amateur radio operators participating in nets.

    Creating a Session

    1. Select a net.
    2. Stations begin in the parked list.
    3. Add stations as they check in.
    4. Reorder stations as required.
    5. Add optional notes.
    6. Save the session.

    Running Order

    • Move stations up or down.
    • Remove stations back to the parked list.
    • Change the running order at any time.

    Quick Add Station

    • Type a callsign or name.
    • Existing stations are added directly.
    • New stations are created automatically.

    Session History

    • Saving a session updates participation data.
    • History is stored locally.
    • History can be downloaded as Markdown.

    Data Storage

    • Data is stored locally in the browser.
    • Export JSON regularly for backup.
